# Tasktra 1.0 development history

This archive contains the durable goals, approvals, work items, workflows,
upgrade records, and completion evidence created while Tasktra developed its
1.0 release. It is historical release evidence, not active configuration for
people adopting Tasktra.

The active repository-level `.tasktra` directory intentionally contains only
the self-hosting profile and generated metadata needed to compile the checked-in
agent projections. A local runtime database is created separately by
`tasktra bootstrap` and is ignored by Git.
